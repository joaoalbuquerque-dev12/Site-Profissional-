Rafaela Bassetto — Assistência Técnica Judicial em Psicologia

Site institucional da psicóloga Rafaela Bassetto (CRP 06/175816), desenvolvido para apresentar sua atuação como assistente técnica judicial e parecerista em processos que envolvem conhecimentos da Psicologia.

Sobre o projeto

O site reúne informações profissionais, áreas de atuação, etapas da contratação, perguntas frequentes e canais de contato. A interface foi criada com foco em clareza, acessibilidade e adaptação a computadores, tablets e celulares.

Funcionalidades

Layout responsivo;

Menu de navegação para dispositivos móveis;

Navegação suave entre as seções;

Seção de perguntas frequentes em formato de acordeão;

Botões de contato direto pelo WhatsApp;

Links para telefone, e-mail e Instagram;

Cabeçalho com efeito visual durante a rolagem;

Atualização automática do ano no rodapé;

Link de salto para facilitar a navegação por teclado.

Tecnologias utilizadas

HTML5;

CSS3;

JavaScript puro (Vanilla JS).

O projeto não depende de frameworks, gerenciadores de pacotes ou processo de compilação.

Como executar localmente

Clone o repositório:

git clone URL_DO_REPOSITORIO

Entre na pasta do projeto:

cd NOME_DO_REPOSITORIO

Confirme que os arquivos principais estão nomeados como index.html, styles-compact.css e script.js.

Abra o arquivo index.html no navegador.

Também é possível executar o projeto com uma extensão de servidor local, como o Live Server no Visual Studio Code.

Publicação no GitHub Pages

Envie todos os arquivos e a pasta assets para o repositório;

No GitHub, acesse Settings → Pages;

Em Build and deployment, selecione Deploy from a branch;

Escolha a branch main e a pasta / (root);

Clique em Save e aguarde a publicação.

Personalização

Textos e links: edite o arquivo index.html;

Cores, tipografia e espaçamentos: edite as variáveis no início de styles-compact.css;

Menu móvel, acordeão e ano do rodapé: edite o arquivo script.js;

Fotos profissionais: substitua os arquivos em assets/fotos/, preservando os nomes utilizados no HTML.
